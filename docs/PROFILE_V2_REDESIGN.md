# Profile V2 — teste visual

Substituição visual do `/profile` com Components V2. O teste usa Container, Section, Thumbnail, Separator, Text Display, Media Gallery e botões como acessórios de Section. A lógica de dados permanece a mesma; a mudança é concentrada na composição da interface.

Objetivos: reduzir a sensação de embed antigo, concentrar a identidade no cabeçalho, transformar dados em blocos escaneáveis, usar mídia contextual e deixar ações próximas do conteúdo correspondente.
