# Card frames (Goal Bound)

Drop **empty** card frame PNGs here (transparent hole for the face + space for stats).

Suggested names (match OVR bands):

| File | OVR range | Use |
|------|-----------|-----|
| `bronze.png` | < 65 | low overall |
| `silver.png` | 65–74 | mid |
| `gold.png` | 75–84 | high |
| `special.png` | 85–89 | promo / egoist glow |
| `newgen.png` | 90–94 | New Gen look |
| `icon.png` | 95–99 | top tier |

Optional by pull rarity (if you prefer rarity over OVR):
`locked.png`, `egoista.png`, `new_gen.png`, `coach.png`

- Prefer **PNG** with transparency
- Keep under ~500KB each when possible
- Same size for all frames (e.g. 420×600) makes composition easier

The bot will composite character faces + stats on top of these frames.
