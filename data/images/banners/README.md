# Banner art

Place GIF files here for `/banners` panels:

| File | Where it appears |
|------|------------------|
| `standard.gif` | Standard Banner panel |
| `coaches.gif` | Coaches panel |
| `hub.gif` | `/banners` hub (optional) |

**Recommended size:** exactly **400×225** (16:9), under ~1.5 MB.

Both `standard.gif` and `coaches.gif` should be the **same dimensions** so one doesn't look bigger than the other in Discord embeds.

The bot loads them automatically when the corresponding panel opens. If a file is missing, the panel still works — just without the image.
